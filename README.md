# Barrio — una ciudad sin apuro

Juego cozy para construir una ciudad moderna que se arma sola. Sin objetivos, sin números: solo construir.

- **Jugar:** https://jedbweb-ai.github.io/barrio/ (se puede instalar en el celular y funciona sin internet)
- **Sin internet en la computadora:** abrir `dist/index.html` con doble clic.

## Desarrollo
- Código del juego: `src/main.js` · plantilla: `src/index.html` · íconos y manifiesto: `public/`
- `npm install` y luego `npm run build` → genera `dist/` (un único HTML autónomo + archivos de la app instalable).
- Cada push a `main` publica automáticamente en GitHub Pages.
